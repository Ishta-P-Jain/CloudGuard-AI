# ☁️ CloudGuard AI

CloudGuard AI is an AI-powered cloud security auditing platform that helps users identify and understand security misconfigurations in cloud environments. It scans cloud resources, detects potential vulnerabilities, calculates an overall security score, and provides AI-generated explanations along with recommended remediation steps.

Designed as an educational and beginner-friendly project, CloudGuard AI demonstrates how modern cloud security tools work by integrating cloud resource scanning, backend APIs, artificial intelligence, and an interactive web dashboard into a single application.

## ✨ Features

- 🔍 Scan cloud resources for security misconfigurations
- 📊 Generate an overall cloud security score
- ⚠️ Detect vulnerabilities across cloud services
- 🤖 AI-powered explanations and remediation suggestions
- 📄 Download scan reports as PDF
- 📈 Interactive dashboard with security insights
- 🛡️ Local cloud environment using LocalStack for safe testing
